## 📖 Tentang Project

Project ini merupakan aplikasi web sederhana berbasis **Laravel** yang digunakan untuk mengelola daftar kontak (*Contact List*).

Aplikasi ini memungkinkan pengguna untuk menyimpan data kontak ke dalam database **MySQL**, serta melakukan pengelolaan data secara penuh melalui sistem **CRUD** (Create, Read, Update, Delete) dengan tampilan yang sederhana dan mudah digunakan.

---

## ✨ Fitur Utama

- ✅ Menambahkan data kontak baru
- ✅ Melihat seluruh daftar kontak
- ✅ Mengubah (Edit) data kontak
- ✅ Menghapus data kontak
- ✅ Data tersimpan ke database MySQL
- ✅ Interface sederhana dan mudah digunakan
- ✅ Validasi input data
- ✅ Responsive layout

## ⚙️ Sistem CRUD

Aplikasi ini mengimplementasikan empat operasi dasar pengelolaan data:

| Operasi | Icon | Penjelasan |
| ------- | :--: | ---------- |
| **Create** | ➕ | Menambahkan data kontak baru ke dalam sistem. |
| **Read**   | 👀 | Menampilkan seluruh daftar kontak yang tersimpan. |
| **Update** | ✏️ | Mengubah data kontak yang sudah ada sebelumnya. |
| **Delete** | 🗑️ | Menghapus data kontak dari database. |

---

## 🗄️ Database

Seluruh data kontak akan disimpan ke dalam database **MySQL** menggunakan sistem **migration** bawaan Laravel, sehingga struktur tabel dapat dibuat secara otomatis dan data akan **tetap tersimpan** meskipun halaman web di-*refresh*.
